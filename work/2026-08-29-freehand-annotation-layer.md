# 자유필기 오버레이 작업 기록

## 완료한 일

- 왼쪽 원함수 그래프와 오른쪽 연동 그래프 위에 각각 독립된 투명 Canvas 필기 레이어를 추가했다.
- `이동 / 펜 / 지우개 / 전체 지우기` 도구를 그래프 우측 상단에 제공했다.
- 기본 도구를 `이동`으로 두어 JSXGraph의 줌·팬과 왼쪽 `y=t` 드래그가 기존처럼 작동하도록 했다. 펜/지우개 모드에서만 필기 레이어가 포인터 이벤트를 받는다.
- 필기점은 화면 크기에 대한 0~1 정규화 좌표로 저장한다. 따라서 반응형 크기 변경이나 고해상도 화면에서도 획 비율이 유지되며, 수학 그래프 객체와 선생님 메모가 서로 영향을 주지 않는다.
- Zustand에 `leftInkStrokes`, `rightInkStrokes`를 분리 저장해 두 패널 간 필기가 섞이지 않게 했다.

## 검증

- 자유필기 단위 테스트: 이동 모드에서는 그리지 않음, 펜 획의 정규화 저장, 전체 지우기, 닿은 획만 지우기
- 스토어 테스트: 좌·우 필기 상태 분리
- 기존 52번 문제 E2E 테스트는 그래프 렌더링 Canvas를 명확히 지정하도록 보강하여 필기 Canvas 추가 후에도 연동 검증을 유지
- `npm test`: 137개 통과, 21개 테스트 파일
- `npm run lint`: 새 경고 없음 (`LinkedFunctionPanel.jsx`의 기존 경고 2개만 유지)
- `npm run build`: 성공
