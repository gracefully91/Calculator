# 오른쪽 그래프 프리셋과 보기 범위 작업 기록

## 발견한 문제

도메인을 비워 둔 왼쪽 식도 실제로는 `x=-8..8`만 그려지고 있었다. Canvas 시절 안전한 초기 표시범위로 쓰던 값이 JSXGraph의 함수 샘플 구간까지 전달된 것이 원인이다. 따라서 수식이 끝난 것이 아니라, 렌더러가 임의의 구간에서 멈춘 상태였다.

## 수정

- 무한 x 도메인은 JSXGraph 보드의 현재 보이는 x 범위를 함수 그래프의 동적 샘플 구간으로 사용한다. 팬/줌 뒤에도 그 범위에 맞춰 계속 보인다.
- 각 그래프에 `보기 범위`를 추가해 x 최소/최대와 y 최소/최대를 직접 설정할 수 있게 했다.
  - 이는 **화면에 보이는 좌표창** 설정이다.
  - 조각함수의 `구간 설정`은 여전히 함수가 정의되는 x 도메인 설정이다. `y=f(x)`에서 y 값 범위로 함수를 잘라내는 별도 기능은 수학적으로 다른 규칙이므로 혼동하지 않도록 추가하지 않았다.

## 오른쪽 그래프 구조

오른쪽은 하나의 고정 결과창이 아니라 선택 가능한 두 번째 그래프가 됐다.

| 모드 | 입력 | 결과 |
| --- | --- | --- |
| 프리셋: `y=t` 교점 개수 | 없음 | x축 `t`, y축 `f(x)=t`의 교점 개수 `h(t)` |
| 프리셋: 도함수 | 없음 | 왼쪽 원함수의 수치 미분 `f′(x)` |
| 사용자 수식 `g(x)` | MathLive 수식 입력 | 독립된 두 번째 그래프 |

프리셋은 왼쪽 식과 연동해 즉시 계산되며, 사용자 수식 모드에서만 오른쪽 입력칸과 필요한 파라미터 슬라이더가 나타난다.

## 검증

- 프리셋 목록·수치 도함수·사용자 수식 입력·x/y 보기 범위·스토어 상태에 대한 테스트를 추가했다.
- 전체 테스트 파일을 두 묶음으로 실행: 142개 테스트, 22개 파일 통과.
- `npm run lint`: 새 경고 없음. 기존 `LinkedFunctionPanel.jsx`의 effect 경고 2개만 유지.
- `npm run build`: 성공.
