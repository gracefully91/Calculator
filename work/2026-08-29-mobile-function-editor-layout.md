# 모바일 함수 편집 레이아웃 작업 기록

## 문제

작은 화면에서 원함수 그래프가 정사각형으로 큰 면적을 차지해, 그래프와 같은 카드 안에 있던 함수 목록/입력행이 첫 화면 아래로 밀렸다. 내용이 잘린 것은 아니지만 스크롤 전에는 입력 기능이 없는 것처럼 보였다.

## 변경

- 모바일(`768px` 이하)에서 왼쪽 원함수 영역을 두 카드로 분리했다.
  - 그래프 카드: 제목, `y=t` 드래그, 그래프 조작 도구
  - 함수 편집 카드: `함수 편집 · N개` 아코디언과 수식·구간·파라미터 편집
- 함수 편집 아코디언은 기본으로 열어 두었다. 사용자가 접을 수는 있지만, 처음부터 입력칸을 숨기지 않는다.
- 모바일 그래프 비율을 `4:3`으로 낮추고 최소 높이를 `230px`로 조정해 첫 함수 편집 카드가 더 빨리 나타나게 했다.
- 데스크톱 레이아웃은 기존처럼 하나의 연속된 계산기 카드로 유지한다.

## 검증

- Panel 구조: 기본으로 열린 함수 편집 아코디언 확인
- CSS 구조: 모바일 카드 분리·아코디언·열 레이아웃 규칙 확인
- Panel/App 반응형 회귀 테스트: 34개 통과
- `npm run build`: 성공
- `npm run lint`: 새 경고 없음. 기존 `LinkedFunctionPanel.jsx` 경고 2개만 유지
