# 연동 그래프 계산기 UI 리디자인

## 배경

기존 화면은 그래프, 함수 입력, 연동 결과가 단순히 나열되어 있었다. 목표 레퍼런스처럼 **그래프가 중심이고 함수 입력이 하단 시트에 머무르는 계산기 경험**으로 재구성했다.

## 변경 사항

- 넓은 화면에서는 좌우에 동등한 두 개의 그래프 계산기 카드를 배치하고, 768px 이하에서는 세로로 쌓이게 했다.
- 왼쪽 카드는 `f(x)` 원함수, `y=t` 드래그 안내, 격자형 그래프 무대, 함수 입력 시트, 조각/도메인/파라미터 제어를 가진다.
- 오른쪽 카드는 같은 크기의 `h(t)` 결과 그래프, Trace On 스위치, 현재 교점 수 읽기값을 가진다.
- 하단 연결 바는 왼쪽 `y=t`와 오른쪽 `h(t)`가 공유하는 현재 `t`를 보여 준다.
- Canvas 곡선과 점을 청록 계열로 통일하고, 투명 캔버스 배경에 눈금 격자를 추가해 그래프 가독성을 높였다.
- 기존 조각함수 편집, 열린/닫힌 경계, 파라미터 슬라이더, 표시/숨김, 드래그 및 Trace 기능은 유지했다.
