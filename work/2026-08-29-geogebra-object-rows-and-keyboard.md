# GeoGebra형 객체 목록과 공용 수식 키보드 작업 기록

## 목표

모바일·데스크톱에서 그래프와 함수 목록이 분리되어 보이던 화면을, GeoGebra처럼 **색 원 + 식 + 메뉴**가 한 줄에 있는 수학 객체 목록으로 정리한다. 이 패턴은 왼쪽 원함수와 오른쪽 연동 그래프에 모두 적용한다.

## 구현

- 왼쪽 함수 목록
  - 각 행의 왼쪽 색 원은 해당 그래프와 끝점의 실제 색을 보여 주며, 누르면 그 객체만 표시/숨김 처리한다.
  - `f:`, `g:`, `h:` 등의 이름과 MathLive 수식 입력을 한 줄에 둔다.
  - `⋮` 메뉴 안에 x 구간, 끝점 포함 여부, 삭제를 모았다.
  - 아래 `＋ 입력…`은 기존 조각함수의 다음 구간이 아니라, 기존 식과 x 범위가 겹칠 수 있는 **독립 그래프**를 만든다. 기존 조각함수끼리의 도메인 겹침 검증은 그대로 유지한다.

- 오른쪽 연동 그래프
  - 프리셋 `h(t)`(교점 개수), `f′(x)`(도함수), 사용자 수식 `g(x)`을 같은 객체 행으로 표시한다.
  - 오른쪽 색 원도 표시/숨김을 제어한다.
  - 프리셋 변경은 `⋮` 메뉴에 두고, `＋ 입력…`은 사용자 수식 모드로 바로 전환한다.

- 가상 수식 키보드
  - 각 입력칸의 MathLive 키보드·메뉴 아이콘을 숨기고 공유 가상 키보드 한 개만 사용한다.
  - `함수 목록` 헤더의 `⌨ 수식 키보드` 버튼으로 열고 닫는다. 수식칸에 초점을 둔 뒤 이 버튼을 누르면 해당 입력을 계속 편집할 수 있다.

## 검증

- `npx vitest run`: 23개 파일, 148개 테스트 통과.
- `npx oxlint`: 실패 없음. `LinkedFunctionPanel.jsx`의 기존 effect 경고 2개만 유지.
- `npx vite build`: 성공. JSXGraph 의존성의 `eval` 알림과 대형 번들 안내만 출력된다.

## 보기 초기화

원함수 `f(x) 그래프`와 오른쪽 연동 그래프 헤더의 `↻`는 식·파라미터·필기·`y=t` 위치를 바꾸지 않는다. 각 패널의 팬/휠 확대 또는 `보기 범위`에서 변경한 x/y 좌표창만 독립적으로 기본값 `x,y = -8..8`로 되돌린다.
