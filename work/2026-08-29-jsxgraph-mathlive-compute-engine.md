# JSXGraph · MathLive · Compute Engine 전환 기록

## 목표

기존의 2패널 연동 계산기(왼쪽 `f(x)`, 오른쪽 `h(t)=y=t` 교점 수)를 유지하면서, 직접 그린 Canvas 그래프와 텍스트 코드 편집기를 수학 전용 브라우저 도구로 단계적으로 교체한다.

이번 전환에서는 Equation.io를 제외했다. Equation.io는 완성형 계산기라 현재 앱의 조각함수, `t` 드래그, 교점 수, trace 상태를 다시 구현하거나 두 상태 모델을 동기화해야 한다. 반면 JSXGraph는 현재 React 상태에서 받은 함수·점·드래그 콜백을 그대로 보드 객체에 연결할 수 있다.

## 적용한 구성

| 계층 | 이번 작업 | 기존 기능과의 관계 |
| --- | --- | --- |
| 그래프 | `jsxgraph` 보드로 함수, 열린/닫힌 점, `y=t` 선과 드래그 핸들을 렌더링 | 두 패널은 독립적으로 이동·확대되고, `t` 값은 기존 Zustand 흐름을 통해 오른쪽 `h(t)`에 즉시 전달된다. |
| 수식 입력 | `mathlive`의 `<math-field>` | 사용자는 분수·루트·지수 형태로 입력하고, 기존 데이터 모델에는 호환 가능한 ASCII 수식으로 저장한다. `a(x)` 같은 매개변수 곱셈은 `a*(x)`로 복원한다. |
| 수식 의미 | `@cortex-js/compute-engine` | 기존 ASCII 수식을 MathLive LaTeX로 바꾼 뒤 MathJSON으로 파싱한다. `abs(x)`, `sqrt(x)`를 문자 곱셈으로 오해하지 않도록 변환 순서를 고정했다. |
| 수치 계산 | 기존 `mathjs` | 조각함수 평가·근 탐색·52번 문제 검증은 이미 검증된 계산 경로를 유지한다. Compute Engine MathJSON은 미분/단순화 같은 다음 수학 기능의 공용 기반이다. |

## 호환성과 안전장치

- `GraphCanvas`의 기존 Canvas는 jsdom 테스트와 예외 환경의 폴백으로만 남겼다. 실제 레이아웃 크기를 얻을 수 있는 브라우저에서는 JSXGraph 보드가 이를 대체한다.
- 기존 `expr` 문자열과 `mathjs` 계산 계약을 바꾸지 않았으므로, 조각 도메인·열린/닫힌 점·자동 파라미터 슬라이더·교점 수·trace가 그대로 유지된다.
- 손글씨는 수학 객체와 별도의 투명 Canvas 오버레이로 붙이는 것이 맞다. 이번 단계는 보드와 입력/계산 경계를 분리했으며, 필기 저장·지우개·펜 도구는 다음 UI 단계에서 이 경계 위에 추가한다.

## 검증

- `npm test`: 133개 테스트, 20개 파일 통과
- `npm run lint`: 신규 경고 없음. `LinkedFunctionPanel.jsx`의 기존 경고 2개만 유지
- `npm run build`: 성공

빌드 결과는 JSXGraph의 전체 기능 포함으로 초기 JavaScript가 약 5.9MB이다. 현재는 상호작용 수학 기능을 우선했으며, 다음 성능 단계에서는 그래프 보드의 동적 import/청크 분리를 검토한다.
